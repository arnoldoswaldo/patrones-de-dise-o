
🧩 # Patrones de diseño 

## Descripción

Este repositorio contiene el desarrollo del laboratorio de patrones de diseño del curso Ingeniería de Software II. Se presentan implementaciones en Python organizadas en las  categorías principales de patrones de diseño.

 💻 ## Organización 
 
El repositorio cuenta con 3 directorioss donde se encuentran los codigos de cada tipo de patron, y 2 archivos pdf, 1 con el planteaiento del laboratorio y otro archivo llamado salidas que cuenta con imagenes de los resultados obtenidos al correr cada uno de los codigos 

Acontinuacion una pequeña descripcion de cada caso.
### 🧬 1. Patrones creacionales 

Se enfocan en los mecanismos de creación de objetos.

Directorio: [`creacionales/`](./creacionales/)

Patrones documentados en el material del laboratorio:
- Builder
- Prototype
- Singleton
- Factory

### 🏗️ 2. Patrones estructurales

Se encargan de organizar las relaciones entre clases y objetos.

Directorio: [`Estructurales/`](./Estructurales/)

Patrones documentados en el material del laboratorio:
- Adapter
- Decorator
- Facade
- Composite

### ⚛️ 3. Patrones de comportamiento 

Definen cómo interactúan y se comunican los objetos.

Directorio: [`comportamiento/`](./comportamiento/)

Patrones documentados en el material del laboratorio:
- Strategy
- Observer
- Command
- Template Method
- State
